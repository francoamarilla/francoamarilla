## Proyectos destacados
 
### [Causario](https://francoamarilla.github.io/causario-demo/login) — sistema de gestión para estudios jurídicos
En producción en un estudio jurídico de Córdoba (etapa piloto). Sincroniza automáticamente los movimientos de causas desde ExtraNet (Poder Judicial de Córdoba) y el PJN, y se instala en la PC central del estudio con actualización automática.
`Java` · `Spring Boot` · `Angular` · `PostgreSQL` · `Testcontainers` · `GitHub Actions (CI/CD)`
**[Ver demo en vivo](https://francoamarilla.github.io/causario-demo/login)** · Repositorio privado (código disponible a pedido)
 
### [Sticky Fingers](https://github.com/francoamarilla/StickyFingers) — sistema de pedidos para una hamburguesería
Estuvo en producción para un local real: carta y checkout para clientes, y panel de gestión con pedidos en tiempo real, ofertas e informes de ventas.
`Java 21` · `Spring Boot 3` · `Spring Security + JWT` · `WebSocket (STOMP)` · `Angular` · `PostgreSQL` · `Docker`
 
### [Pura Crema](https://github.com/francoamarilla/PC_Dashboard-) — gestión para un emprendimiento de reventa de ropa
Sistema interno del emprendimiento del que soy socio: costo real por prenda, ventas trazables por socio y panel de rentabilidad.
`Python` · `FastAPI` · `SQLAlchemy` · `PostgreSQL` · `React 19` · `TypeScript` · `pytest`
 
### [StockAPI Manager](https://github.com/francoamarilla/StockAPI-Manager) — stock, ventas y reportes
API REST con autenticación JWT y roles, documentada con Swagger/OpenAPI, y frontend en React.
`Java 21` · `Spring Boot 3` · `React 18` · `TypeScript` · `PostgreSQL`
